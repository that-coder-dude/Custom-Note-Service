# 📝 Custom Notes App

A minimalist and responsive Notes App built with HTML, CSS, and JavaScript. This app allows users to register, log in, and manage their personal notes using a JWT-authenticated backend.

## 🚀 Features

- User Registration & Login
- JWT-based Authentication
- Create and View Notes
- Minimalist UI with Responsive Design
- Logout functionality

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express, MongoDB (with Mongoose)
- **Auth:** JSON Web Tokens (JWT)

✅ Usage
Register with a username and password.
Log in using those credentials.
Create and view notes.
Use the logout button to end your session.
